Nepali String Localizer

Context-Aware UI Translation for Open Source

Translate isolated English UI strings into Nepali for software localization projects like KoboToolbox. The open-weight model runs entirely in your browser: no server, no API key, and after the first load, no internet.

The first translation downloads the model (about 1 to 1.5 GB) and caches it in your browser. Later visits load from the cache and work offline.
